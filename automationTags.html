Automation tags
This feature is only available in SimpleOne Label Maker Pro Edition
Tag Description
[#] or [NUMBERCOUNTER] sequential number with customizable start counter and intervals
[#R] random number with customizable start and end
[UNIQUEID] unique identifier
[TIMESTAMP] current timestamp with date
[DATE] current date
[CURRENTTIME] current timestamp without date
  • Tags are case sensitive
  • You can use a combination of different tags
  • If you use multiple instances of the same tag within the same label, only the first instance will be recognized as an automation tag
How to save and reuse tags as part of the label design:
  • Add automation tags to your label design
  • Go to Print > Populate Tags
  • Go to Command Bar > Save
This option saves tags as part of the label design, you can re-populate tags to generate different values for each print.
How to render tag values directly into labels:
  • Add automation tags to your label design
  • Go to Command Bar > Automation Tags > Render Tags Now
  • Go to Command Bar > Save
This option renders tags into actual values.
